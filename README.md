# Video-Game-Sales-Analytics-Project

📌 Overview

Este projeto tem como objetivo analisar dados de vendas globais de videogames utilizando Python, SQL e modelagem analítica.

O foco principal foi desenvolver competências práticas em:

Análise Exploratória de Dados (EDA)
SQL para análise de negócio
Pensamento analítico
Interpretação de métricas
Comparação regional de mercado
Estruturação de projeto de dados
🧠 Objetivos do Projeto

Responder perguntas de negócio como:

Quais plataformas dominaram o mercado global?
Quais gêneros possuem maior faturamento?
Existem diferenças culturais entre regiões?
Quais plataformas performam melhor em determinadas regiões?
Como o comportamento do consumidor varia entre América, Europa e Japão?
